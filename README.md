## ⚡ v1.3 里程碑：ABR 双维自适应调教

### 设计哲学：三全目标

**清晰度 + 高帧率 + 跟手** 缺一不可——绝不为跟手牺牲画质（拒绝固定低分辨率/低帧率兜底）。

### 双维缓冲机制

| 维度 | 作用 | 说明 |
|---|---|---|
| **码率缓冲** | 编码吞吐调节 | 帧内容大/轻微超载时降码率（数据量↓），下限 1M |
| **帧率缓冲** | 编码次数调节 | 码率缓冲不够时 fps 120→90 一同分担（ME 成本↓25%） |

**90fps 缓冲搭档档（v1.3 核心）**：
- **码率缓冲时**：complex 帧/轻微超载触发降码率，fps 同步 **120→90**——双缓冲一同分担（顶到 120 后只靠码率缓冲不够跟手）
- **快速降档时**：真超载（≥90ms/窗口确认）fps **120→60→30 一步到底**——90 不做降档中间台阶
- **恢复时**：30→60→90→120 平滑升档（90 是恢复台阶）

### 检测链路（四级递进）

| 信号 | 阈值 | 响应 |
|---|---|---|
| **趋势检测**（GCC Trendline） | 3 帧连续递增 +2ms 且 >10ms | 事前温和降码率 ×0.7（23ms 即响应） |
| **instant 瞬时** | 单帧 >25ms | 降码率（<100ms 温和 ×0.7 / ≥100ms 激进 ×0.3） |
| **窗口确认** | 50ms 窗口 delayDelta>30ms 占 5/7 | 确认超载，码率/fps 降级 |
| **fps 快速降档** | instant ≥90ms 或恢复期反复超载 | 120→60→30（跳过 90） |

### 恢复策略

| 项目 | 参数 |
|---|---|
| fps 恢复 | stable 300ms + watch 300ms + confirmed 信用（30→120 ~0.9s） |
| 码率恢复 | <16M 每 100ms / ≥16M 每 200ms / ceiling 释放 300ms（糊→能看 ~0.5s） |
| 恢复防抖 | 偶发大帧（I 帧/壁纸 95KB）单次免疫，连续 2 次确认才打断 |
| 爬升豁免 | 码率爬升期轻微超载/complex 不打断（climbing 判定） |
| 降档退避 | 3s 内重复降档冷却 ×2（1s→2s→4s→8s 阻尼振荡） |
| 排空豁免 | 降档后 300ms 内不判档（旧队列帧排空） |

### 关键参数（SurfaceEncoder.java）

```java
ABR_INSTANT_TRIGGER_MS = 25    // 瞬时超载阈值
ABR_MILD_INSTANT_MS    = 100   // 温和/激进分界 + 恢复豁免
ABR_FPS_OVERLOAD_MS    = 90    // fps 快速降档阈值
ABR_FPS_LEVELS         = {120, 90, 60, 30}  // 90 = 缓冲搭档 + 恢复台阶
ABR_MIN_BITRATE        = 1M    // 码率地板
降码率 ×0.3（恢复期温和 ×0.7）
```

## 🚀 快速开始

1. 下载 [v1.3 Release](https://github.com/kinewe/PC-kinewe-yinmo/releases/tag/v1.3) 的 zip，解压到任意目录
2. 手机开启 **开发者选项 → USB 调试**（无线使用还需开启「USB 调试（安全设置）」并重启手机）
3. **USB 插线** 双击 `手机投屏.bat` → 自动有线串流（50M/2560/120fps 动态规格）
4. **拔线** → 5 秒后自动切换无线（15M/1920/60fps，WiFi 需与电脑同网段）
5. 投屏中按 `Q` 退出，插回 USB 自动切回有线

> 无线模式首次使用：确保手机与电脑同一局域网，bat 会自动 `adb tcpip 5555` 并保存 IP（`config.txt`），下次免配对。

## 📋 常见问题

**Q：投屏有 ~70ms 延迟，正常吗？**
A：正常。手机→电脑串流管线（捕获→编码→传输→解码→显示）物理极限约 70ms（业界标杆水平）。ABR 管理的是**吞吐维度**（超载排队延迟），基线延迟无法消除。

**Q：为什么有时看到画面模糊？**
A：压力下码率缓冲介入（降码率），恢复期 ~0.5s 回到清晰——这是「保帧率降画质」的瞬时策略，避免卡顿。

**Q：无线模式卡顿？**
A：无线规格 15M/1920/60fps，受 WiFi 抖动影响（28-30ms 常态抖动已被 ABR 爬升豁免处理）。追求极致体验建议 USB 有线。
